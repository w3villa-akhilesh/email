Rules:

- about_applicant: One-line summary of candidate's background and experience
- Gender: "Male"/"Female"/"Other"/"Unknown" (based on name/context)
- Mobile: 10 digits only (remove +91, spaces, hyphens). Return "" if invalid
- matched_keywords: Check each keyword's meaning from the list below against the resume

    * Examples of meaning matching:

      - "project management" matches "project lead", "project coordination", "managing projects"
      - "Ruby on Rails" matches "Rails", "Ruby on Rails", "RoR"
    * Weightage based on match strength:
      - 1.0: Exact match or very close meaning
      - 0.8: Similar meaning
      - 0.6: Related meaning
      - 0.1: Any similarity in meaning
    * If keyword's meaning is found → include with appropriate weightage
    * If no meaning match found → do not include
  - IMPORTANT:
    * Check the MEANING of each keyword, not just exact text
    * Look for similar terms, related concepts, and variations
    * Use EXACT keyword from the list in response
